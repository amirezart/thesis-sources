# گزارش‌های ارائه‌شده به استاد راهنما

این پوشه برای نسخه‌های گزارش و ارائه‌های پژوهشگر به استاد راهنماست. فایل‌های اصلی را با نام و تاریخ مشخص در همین پوشه قرار دهید؛ نسخه‌های قبلی را حفظ کنید.

گزارش‌ها پیشنهادها و پرسش‌های پژوهشگر را ثبت می‌کنند؛ تا زمانی که نظر استاد مستند نشده، پیشنهاد را تصمیم تأییدشده تلقی نکنید. بازخورد استاد را با تاریخ و وضعیت جداگانه ثبت کنید.

ریپو عمومی است؛ پیش از انتشار فایل‌ها، اطلاعات شخصی و محتوای قابل انتشار را بررسی کنید. قرارگرفتن فایل در این پوشه به‌تنهایی به معنای انتشار یا ثبت آن در Git نیست.
